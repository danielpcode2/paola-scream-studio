# Paola Scream Studio — Windows

Versión para Windows **en preparación**. Aún no hay código.

## Plan

- C# / .NET 8 con WinUI 3 para la interfaz.
- `Windows.Graphics.Capture` para grabar pantalla, ventana o área.
- Media Foundation / FFmpeg para cámara, micrófono, audio del sistema y exportación.
- Mismo formato de proyecto (`project.json`) que la versión de Mac, para abrir proyectos en ambos sistemas.

## Requisitos previstos para desarrollo

- Windows 10 (1903) o superior / Windows 11
- Visual Studio 2022 con la carga de trabajo "Desarrollo de aplicaciones de escritorio de .NET" y el SDK de Windows App
- .NET 8 SDK

Los pasos para levantarla en desarrollo se añadirán aquí cuando exista el proyecto.
